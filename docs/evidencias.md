# Evidências

## Etapa 01

Nesta etapa, a entrega é composta principalmente pela proposta e especificação inicial do projeto, acompanhadas por uma fundação técnica executável.

### Evidências

- estrutura inicial do repositório criada;
- README criado;
- proposta documentada;
- arquitetura inicial definida;
- frontend React, TypeScript e Vite compilado;
- backend Node.js, TypeScript e Express compilado;
- endpoint `GET /health` verificado;
- repositório versionado com Git;
- entrega identificada pela tag `etapa-01`.

Evidências visuais das funcionalidades da aplicação serão adicionadas conforme a implementação evoluir nas próximas etapas.
